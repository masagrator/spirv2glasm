# The `G2S_*` switches

Every rule this converter emits was READ, and every one of them
has an off switch, so a disagreement can be bisected without
editing code.  The convention is `G2S_NOX=1` restores the refusal
or the older reading X replaced: when a listing regresses, turn
the newest switches off one at a time to find the rule that did
it.

A switch whose name ends `DBG` is a diagnostic -- it prints to
stderr and changes no output.  `G2S_TRACE` and `G2S_ONLY` drive
the ORACLE's hooks, not this converter (HANDOVER.md §3).

## Named in the notes, not in the code

A note is a dated record and keeps the switch it was measured with, so a
name here is not a bug in the note -- it is a bug in anyone who reads the
note and types the name.  The ones that matter are the rules that BECAME
THE DEFAULT: the switch survives as its `NO` form, so `G2S_LOCALREG=1`
from a 2026 note is `G2S_NOLOCALREG=1` inverted today.

Hook-side switches (`runtime/g2s_hook.c`, which instruments the ORACLE)
are not converter switches and are not listed.
